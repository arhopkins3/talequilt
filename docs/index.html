Optional. Without a token the console reads public data at GitHub's anonymous limit of 60 requests an hour, so it refreshes every ten minutes. With a token it refreshes every minute and also shows which pull requests propose ADR files. The token stays in this browser's local storage, is sent only to api.github.com, and is never written to the repository.
